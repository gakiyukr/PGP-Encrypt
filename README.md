# 資料夾 PGP 加密與簽署工具（tar + GPG，壓縮可選 xz／zstd／不壓縮；另有 7z 密碼模式與純 C# 公鑰加密）

三種加密方式，共用同一份清單、進度條與紀錄面板：

- **PGP 公鑰加密與簽署**：資料夾先以 tar 打包（壓縮格式可選：xz 高壓縮率、zstd 快速，或不壓縮僅打包），再以 PGP 公鑰加密並簽署，產出單一 `.tar.xz.gpg`／`.tar.zst.gpg`／`.tar.gpg` 檔案；單一檔案則直接加密並簽署，產出 `.gpg` 檔案。依賴 GnuPG。
- **密碼加密（7z AES-256）**：以密碼學亂數產生密碼，交由 7z 打包並以 AES-256 加密（含標頭加密），產出 `.7z` 檔案。適合沒有對方公鑰、只能靠密碼傳遞的場合；**密碼只顯示一次，關閉視窗後無法找回**。依賴 7-Zip。
- **公鑰明文加密（純 C#）**：**不呼叫 gpg.exe**，直接解析對方的 ASCII-armored 公鑰（`gpg --armor --export` 的輸出），以內建 OpenPGP 實作加密。適合需要在無 GnuPG 環境中加密、或希望完全排除第三方程序的場合。**只加密、不簽署**（接收方仍需 gpg 解密）。目前僅支援 **RSA 公鑰**（cv25519/Ed25519 尚在調試）。

## 檔案說明

| 檔案 | 用途 |
|------|------|
| `PGPEncrypt.exe` | 主程式（.NET 單一執行檔，含 GUI 與命令列模式） |
| `EncryptTool.cs` | C# 原始碼（修改後以 `build.bat` 重新編譯） |
| `build.bat` | 編譯腳本（使用 Windows 內建 csc.exe，無需安裝 SDK） |

## 使用方式

### 方式一：GUI

1. 雙擊 `PGPEncrypt.exe`。
2. 把要加密的**資料夾或檔案**拖進視窗清單（可一次拖多個）。
3. 在「加密方式」選單選擇：
   - **PGP 公鑰加密與簽署**：需在下方選單選擇加密對象（公鑰）。
   - **密碼加密（7z AES-256）**：可設定壓縮等級、密碼位數，以及是否將密碼寫入檔名。
   - **公鑰明文（內建加密）**：貼上對方的 ASCII-armored 公鑰文字（`gpg --armor --export <KeyID>` 的完整輸出），程式會自動識別並顯示金鑰資訊。不呼叫 gpg.exe，目前僅支援 RSA 公鑰。
4. 依模式設定其餘選項：
   - PGP 模式的「壓縮格式」：**xz**（預設，壓縮率最高、較慢）、**zstd**（速度快、壓縮率中等，僅在本機 `tar.exe` 實測支援時才出現）、**不壓縮（僅打包 tar）**（最快，適合影片、音訊等已壓縮內容）。
   - 密碼模式的「壓縮等級」：不壓縮（最快）／快速／標準／最大壓縮。
5. 若要將清單中的所有項目封裝為單一檔案，勾選「將清單中的所有項目合併為單一壓縮檔」；PGP 模式會接著選擇輸出位置，密碼模式則輸出為來源同層的 `合併加密.7z`。
6. 按「開始加密並簽署」（密碼模式為「開始加密（7z 密碼）」）。加密在背景進行，下方進度條即時顯示進度，處理中不會凍結視窗。
7. 密碼模式的密碼會顯示在紀錄面板，**請立即複製保存**。

### 方式二：拖放到 exe 圖示

把資料夾或檔案直接拖曳到 `PGPEncrypt.exe` 的圖示上，程式會自動開啟 GUI 並預填項目。此方式以 Windows 原生參數傳遞，**不受** cmd 特殊字元（`&`、`|`、`<`、`>`、`^`、括號）限制。

### 方式三：命令列

```bat
PGPEncrypt.exe "C:\path\to\資料夾或檔案" 收件人KeyID或Email [xz|zstd|store]
```

- 最後一個參數為壓縮模式，可省略（預設 `xz`）：`xz` 壓縮率最高、`zstd` 速度快（需本機 tar 支援）、`store` 僅打包不壓縮（也可寫 `tar` 或 `none`）。
- 相容舊寫法：第一個參數為 `-cli` 時予以略過（`PGPEncrypt.exe -cli <路徑> <收件人> [模式]`）。
- 合併多個項目為單一檔案：`PGPEncrypt.exe -combine <輸出檔> <收件人> [模式] <項目...>`
- 密碼模式：

```bat
PGPEncrypt.exe -pw [-len 位數] [-mx 等級] [-toname] [-out <輸出檔>] <項目...>
```

  - `-len`：密碼位數（1–128，預設 27）。
  - `-mx`：7z 壓縮等級（0–9，預設 0 不壓縮）。
  - `-toname`：將密碼寫入輸出檔名（`<名稱>（密碼：xxx）.7z`）。
  - `-out`：自訂輸出檔路徑（自動補 `.7z` 並套用不覆蓋序號）。
  - 不指定 `-out` 時，單一項目輸出為來源同層的 `<名稱>.7z`，多個項目輸出為第一個項目同層的 `合併加密.7z`。
  - 執行完畢後密碼會以 `密碼：xxx` 印在標準輸出，請自行保存。
- 公鑰明文模式（純 C# 加密，不呼叫 gpg.exe）：

```bat
PGPEncrypt.exe -pk <公鑰檔|-> [xz|zstd|store] <項目...>
PGPEncrypt.exe -combine <輸出檔> -pk <公鑰檔|-> [xz|zstd|store] <項目...>
```

  - `<公鑰檔|->` 可以是檔案路徑，或用 `-` 從標準輸入讀取（適合管線或貼上）。公鑰格式為 ASCII-armored（`gpg --armor --export <KeyID>` 的輸出）。
  - 壓縮模式與 PGP 模式相同（`xz`／`zstd`／`store`），可省略（預設 `xz`）。
  - `-combine` 模式將多個項目封裝為單一輸出檔。
  - **只加密、不簽署**。接收方仍需 `gpg -d` 解密（產出標準 `.gpg` 檔）。
  - **目前僅支援 RSA 公鑰**。cv25519/Ed25519 金鑰會被識別但加密後 gpg 無法解密（已知問題，調試中）。

- 在 **cmd** 中執行會等待完成並回傳結束碼（0 成功、1 失敗、2 用法錯誤）；在 **PowerShell 腳本**中請用 `Start-Process -Wait -PassThru` 呼叫（PowerShell 不等待 GUI 子系統程式）。

## 產出位置

輸出檔與來源資料夾放在同一層：

- `C:\Data\我的文件\` → `C:\Data\我的文件.tar.xz.gpg`（xz 模式；zstd 為 `.tar.zst.gpg`，不壓縮為 `.tar.gpg`）
- `C:\Data\報告.pdf` → `C:\Data\報告.pdf.gpg`
- 密碼模式：`C:\Data\報告.pdf` → `C:\Data\報告.pdf.7z`

勾選合併模式時，清單中的檔案與資料夾會共同輸出為一個加密壓縮檔：PGP 模式可自訂名稱及位置，副檔名依壓縮模式為 `.tar.xz.gpg`、`.tar.zst.gpg` 或 `.tar.gpg`；密碼模式輸出為 `合併加密.7z`。
- 同名檔案已存在時自動加序號：`我的文件_01.tar.xz.gpg`、`報告_01.7z`，**不會覆蓋舊備份**。

## 原理與特性

- **單一執行檔、零依賴**：以 Windows 內建 .NET Framework 編譯，Win10/11 免安裝任何執行環境。
- **串流處理**：資料夾的 tar 壓縮串流（xz／zstd）或未壓縮串流以 cmd 原生管線直接送入 GPG，明文 tar 不會落磁碟；單一檔案則直接送入 GPG。
- **壓縮格式**：可於 GUI 下拉選單或命令列參數切換——xz（LZMA2，壓縮率高，預設）、zstd（速度快、壓縮率中等）、或 store 僅打包不壓縮（適合影片等已壓縮內容）。tar 封裝已含壓縮（或選擇不壓縮）時，GPG 內層不再重複壓縮，節省處理時間。
- **加密與簽署**：OpenPGP 公鑰加密後，以 GnuPG 的預設私鑰簽署；收件人解密後可驗證簽署者身分及內容完整性。
- **密碼模式（7z AES-256）**：不經 tar 與 GPG，由 7z 直接讀取來源、打包並加密，明文同樣不落磁碟；密碼以 `RNGCryptoServiceProvider` 產生（62 字元集，取模偏差已排除），非時間或 `Random` 之類可預測的種子。標頭一併加密（`-mhe=on`），未提供密碼時連檔名清單都無法讀取。
- **進度顯示**：GUI 進度條即時估算——資料夾模式以 tar `-v` 已完成項目比對預先走訪的大小清單，單一檔案模式以 gpg 輸出檔長度對輸入大小估算，密碼模式輪詢 7z 的百分比輸出；命令列模式每 0.3 秒原地更新百分比。估算不觸碰加密串流本身。
- **不覆蓋**：輸出檔名衝突時自動加 `_01`、`_02`… 序號。

## 解密還原

命令列（解密及簽署驗證；首次簽署或私鑰未解鎖時，會跳出 Pinentry 視窗輸入簽署私鑰密碼）：

```bat
gpg -o 我的文件.tar.xz -d 我的文件.tar.xz.gpg
tar -xf 我的文件.tar.xz
```

zstd 模式：

```bat
gpg -o 我的文件.tar.zst -d 我的文件.tar.zst.gpg
tar -xf 我的文件.tar.zst
```

不壓縮模式：

```bat
gpg -o 我的文件.tar -d 我的文件.tar.gpg
tar -xf 我的文件.tar
```

`tar -xf` 會自動辨識壓縮格式。注意：解密端的 `tar` 也必須支援對應的壓縮格式（尤其 zstd），否則請改用 xz 或不壓縮模式。

密碼模式（7z）：

```bat
7z x 報告.pdf.7z -o還原資料夾
```

輸入密碼後即可解開；`7z` 或 7-Zip 圖形介面皆可。Win11 內建的 `C:\Windows\System32\7z.exe` 亦可直接使用。

## 重新編譯

修改 `EncryptTool.cs` 後執行 `build.bat` 即可重新編譯出 `PGPEncrypt.exe`。編譯使用 Windows 內建的 .NET Framework csc.exe，不需要安裝任何 SDK 或開發工具。

## 環境需求

- Windows 10/11（exe 以內建 .NET Framework 4.x 編譯，零額外依賴）
- Windows 內建 `tar.exe`（bsdtar，支援 xz；zstd 依版本與建置而定，程式啟動時會自動偵測）
- GnuPG（Gpg4win）。本工具依序尋找：`C:\Program Files (x86)\GnuPG\bin\gpg.exe` → `C:\Program Files\GnuPG\bin\gpg.exe` → `C:\opt\GnuPG\bin\gpg.exe` → `PATH`
- 7-Zip（僅密碼模式需要）。本工具依序尋找：`C:\Program Files\7-Zip\7z.exe` → `C:\Program Files (x86)\7-Zip\7z.exe` → `C:\Windows\System32\7z.exe`（Win11 內建）→ `PATH`。找不到時 GUI 仍可開啟，但選密碼模式會提示；PGP 模式不受影響。

## 注意事項

- 接受資料夾與單一檔案；資料夾會壓縮為 tar 封裝，檔案不會額外封裝。
- 合併模式中，清單根目錄名稱不可重複，否則解壓時可能互相覆蓋；程式會拒絕執行並提示重新命名。
- 磁碟根目錄（如 `C:\`）無法直接加密，請選其子資料夾。
- 影片、音訊、圖片等已是壓縮格式的內容，建議選「不壓縮（僅打包 tar）」：體積本來就壓不掉，可省下白費的壓縮時間。
- zstd 模式會在啟動時實測（以與加密相同的管線方式寫出並讀回）；本機 `tar.exe` 不支援或串流無法讀回時，GUI 不會列出 zstd 選項、命令列會拒絕並提示。解密端的 `tar` 也必須支援 zstd 才能解開 `.tar.zst`。
- 金鑰圈中沒有公鑰時，GUI 會提示先建立或匯入：

```bat
gpg --full-generate-key
gpg --import 對方的公鑰.asc
```

- 加密端必須有可用的私鑰作為簽署身分；若 GnuPG 設定了多把私鑰，請先以 `gpg --default-key <KeyID>` 指定預設簽署金鑰。

### 密碼模式相關

- **密碼只顯示一次**（GUI 顯示於紀錄面板、命令列印於標準輸出），關閉後無法找回，也無法從 `.7z` 反推。請在按鍵後立即複製保存。
- 密碼模式**不做簽署**，無法驗證來源身分；需要驗證身分請改用 PGP 模式。
- 密碼在 7z 命令列中可見（7z 不支援自 stdin 讀取密碼）。若同機有其他使用者，請留意行程清單的短暫暴露。
- 勾選「密碼寫入檔名」時，密碼會出現在檔名中；檔名可能隨檔案複製、同步、備份而外流，請自行評估。
